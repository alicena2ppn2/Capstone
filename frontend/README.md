## 반응·출석 연출과 미션/일기 예외 처리

이웃의 응원/감사는 저장 성공 후 각각 ‘응원을 남겼어요’/‘고마움을 남겼어요’를 1.3초 표시한다. 선택 색·체크 문구는 유지한다. 기존 반응은 한 종류 선택 방식이며 취소 동작을 새로 추가하지 않았다. 같은 선택 재클릭은 중복 처리하지 않고 저장 실패는 재시도 안내를 남긴다. 웹은 localStorage 쓰기 성공 후 상태 변경, 앱은 commitState의 직렬 AsyncStorage 저장 성공 후 안내한다. 실제 상대 전달/읽음이 아닌 로컬 시연이다.

출석 지급 성공에서 새 날짜 영수증이 생긴 경우에만 출석표를 자동으로 닫고 앱 중앙의 작은 ‘오늘 받은 선물’ 패널을 1초 표시한다. 기존 RewardPanel/RewardGlyphDrawing/HouseDecor와 newAttendanceReward를 연결했다. 코인·XP는 실제 수치, 의상·소품은 실제 상품 도형과 이름을 표시한다. 중복 아이템은 지급된 대체 코인 영수증을 그대로 표시한다. 확인 버튼 없이 자동 종료하며 재열기/새로고침으로 반복하지 않는다. 오늘 받은 결과는 출석표에 남는다. 실패 시 출석표를 유지하고 성공 연출을 하지 않는다. 웹 모션 줄이기는 정적 표시, 네이티브는 확대/이동 없는 opacity만 사용한다. 보상량·확률·대체 규칙은 유지한다.

일일 구조는 고정3+활동3 그대로다. 활동의 의미는 challenges.js의 activityGroup으로 관리하며 새 계획에서 같은 의미의 활동을 동시에 추천하지 않는다. 최근 3개 날짜에 제공한 그룹을 덜 반복하고, 후보가 부족하면 부담을 올리지 않고 반복한다. 최근 버거웠어요 응답이면 effort 0을 유지한다. 기존 날짜에 저장된 계획/지급 이력은 재작성하지 않는다. 교체는 오늘의 다른 활동·이미 완료한 의미 그룹과 겹치지 않고 기존보다 높은 effort를 사용하지 않는다. 완료/지급된 슬롯은 교체 불가, 대안이 없으면 유지하며 기존 화면이 안내한다. 최종 서버 선정/교체 정책은 미확정이며 이 규칙은 로컬 추천 개선이다.

서울 자정이 지나면 편집 중 본문·감정·질문을 보존하고 ‘오늘로 이어 쓰기 / 초안으로 남기기’를 제공한다. 오늘 저장 본문/초안이 있으면 유지 또는 합쳐 이어 쓰기를 사용자가 선택한다. 자동 덮어쓰기/자동 저장/자동 보상은 없다. 합친 내용이 2,000자를 넘으면 원본들을 유지하고 안내한다. 지난 초안은 날짜별 진입 버튼으로 새로고침 뒤에도 다시 찾을 수 있다. 초안을 옮기는 작업은 journals/스탬프/완료/보상을 만들지 않으며 오늘 저장 성공에만 기존 날짜별 지급 원장이 적용된다.

과거 일기는 수정 불가지만 삭제 확인 후 날짜와 무관하게 삭제할 수 있다. 본문·감정·연결된 day-diary 답변·해당 날짜 초안을 지우고 journalDates/completed/missionReceipts는 보존해 집계와 중복 지급을 방지한다. 삭제한 글은 초안에서 복원되지 않는다. 기존 자산·백엔드/API 계약은 변경하지 않는다.

관련 코드: 웹 App.jsx/Attendance.jsx/RewardPanel.jsx/Visit.jsx/Diary.jsx, 모바일 GameApp.jsx/RewardPanel.jsx/Visit.jsx/Diary.jsx, 공유 challenges.js/dailyMissions.js/journal.js/rewardFeedback.js/useBriefFeedback.js. 기존 저장 키를 사용하고 새 필드를 강제로 초기화하지 않는다.

검증: 로직 67개 테스트, 웹 build, 모바일 lint/typecheck·iOS/Android/Web export 통과. 임시 Edge에서 출석 4종/중복 대체/실패/재열기/재진입, 이웃 반응 성공/실패/선택 상태, 과거 초안 충돌/합치기와 과거 삭제를 확인했다. 실제 iPhone/Android 화면·실기기 안전 영역/키보드는 미확인이며 실제 사용자 인증/서버 보상/상대 전달은 미연결이다.


## 첫 진입 · 로그인 연결 범위

MY MOCHI 로그인/가입 화면에서 시작한다. 청록·크림 UI와 기존 친구 렌더러, 공식 카카오 로그인·Google 버튼 이미지를 사용한다. A2z 400~600을 유지하며 공급자 버튼 글씨는 공식 PNG에 포함된 스타일이다. 세션 확인 중 홈을 마운트하지 않는다. 설정의 로그아웃은 signOut 성공 후 로그인 화면으로 돌아가며 개발 미리보기도 종료한다. 실패 시 설정에서 다시 시도할 수 있고 게임 저장 데이터는 삭제하지 않는다. 현재 인증 어댑터는 미연결로, 사용자 ID나 임의 토큰을 로그인으로 취급하지 않는다. 실패/취소 시 재시도하고 진행 중 중복 입력을 막는다. 게임 데이터는 초기화하지 않는다.

개발 환경에서만 게임 미리보기 버튼을 제공한다. 웹 `http://127.0.0.1:5180/?preview=game`, 모바일 로그인 화면의 개발용 게임 미리보기. 실제 카카오·Google 인증, 계정별 동기화와 신규 가입/온보딩은 서버 계약·앱 등록·리다이렉트 설정이 필요하다. 게스트/계정 병합은 미확정이며 자동 병합하지 않는다. 약관·개인정보처리방침은 실제 URL이 없어 준비 상태만 표시한다. 자세한 연결 항목은 [AUTH_SETUP.md](AUTH_SETUP.md).

## 일일 미션과 일기

매일 작은 루틴 3개(출석/일기/다른 이웃 방명록) + 새로운 발견 3개, 총 6개. 각 영역 N/3 표시. 전체 완료 강제·벌점 없음. 고정 미션은 실제 기능 저장 성공에 연결하며 방문/초안/실패/샘플 글은 완료가 아니다. 출석은 기존 지급만, 일기는 일기 보기/쓰기, 방명록은 이웃 둘러보기. 활동은 시작(무보상)→해냈어요→완료; 보류/교체는 보상 없음. 날짜별 활동 3개는 저장돼 새로고침으로 바뀌지 않는다. 이전 전역 3회 제한을 사용하지 않고 날짜/활동 슬롯별 지급 원장으로 중복을 막는다. 선정·교체·인증의 출시 정책은 서버 합의 전이다.

오늘의 준비/바깥 발견/작은 연결의 기존 작은 행동 조건·부담 응답·같은 목적 대안 활용. 준비나 혼자 외출을 교류로 계산하지 않는다. 음악/음식은 언제든 수정하는 취향 프로필, 보상 없음.

홈/도전/기록에서 같은 날짜의 공통 일기 편집기를 연다. 80자 전용 입력 제거, 최대 2000자·공백 금지·한 줄 가능. 질문+다른 질문과 감정 5종은 선택 사항. 질문 변경은 글 유지/자동 삽입 없음. 초안 journalDrafts와 저장 본문 journals 분리, 이동/복귀·새로고침 복원, 초안은 스탬프/완료/보상 없음. 저장 중/성공/실패/재시도 제공, 실패 시 글 유지. 당일 수정·삭제·삭제 후 재작성 가능, 지난 날짜 읽기만. 삭제 시 본문/감정/답변/초안 정리, 날짜·완료·지급 원장 보존. 수정/재작성으로 보상·날짜 집계 증가 없음. 날짜 목록·월별 달력 유지.

## 성장·출석·상점

LV=1+floor(XP/100), 실제 신규 XP0/90코인/감자, 명시적 demo만 540코인. 현재 로컬 시연 활동 15XP/25코인, 새로운 행동 5XP 추가; 일기 15/25. 방명록 미션 추가 보상은 합의 전 보류. 출석은 기존 주간 계획의 XP5/8/10·코인10/20/30·가끔 옷/소품, 기존 지급 경로 한 번만. 전부6개 보너스 추가 없음. 서버는 다른 수치를 사용하므로 출시 보상 정책은 명세서 합의 표에서 확인한다.

주간 외출/교류 각2회·일기 다른 날짜3일은 각30XP/30코인, 월간 외출8회·일기10일 각60/60. 서울 월요일/월초 경계, 중복 집계/지급 방지·과거 원장 유지. 실제 행동은 사용자 확인, 센서 검증 아님.

실제 친구12종: 기존 감자 기본, 토끼LV3무료, 구름LV5/300, 양LV8/450, 거북LV12/600, 펭귄 누적 현실 행동10회 무료와 추가6종(아래 최종표). 옷4종120~300·소품/풍경16종90~520. 구매/장착/배치/해제는 별개이며 일반 잠금 상품의 외형·이름·가격·LV를 공개한다. 목표 선택 기능은 제거했다. 기존 애칭은 해당 친구만 이관하며 소개는 짧은 성격·취향·습관으로 표시한다. 깜빡임·터치/키보드·새 완료/새 의상 축하·모션 줄이기를 유지한다.

기존6종에 밀루·라니·루루·포포·메루·도토를 추가한 실제 상품12종이다. 기존 ID를 유지하며 A/B/C는 별도 상품이 아니다. 레벨 달성은 구매만 열고 자동 지급·자동 선택하지 않는다. 미구현8종은 상품에 없으며 LV30~100 조건은 미정이다.

### 가격 산정과 진행 예시

현재 고정3+활동3 구조를 확인했다. 활동 1개=15XP/25코인, 처음 수행하는 활동에는5XP 추가. 일기=15XP/25코인, 방명록=0(정책 대기), 출석은 기존 랜덤 지급만(코인10/20/30, XP5/8/10, 의상·소품 후보 및 중복30코인 대체). 과거 전역3회 한도를 가격 산정에 사용하지 않았다. 현재 활동은 하루3슬롯의1회 지급이고 일기/출석은 각 원장으로 별도 중복 방지한다. 레벨=1+floor(XP/100), 시작90코인/시연540코인, 주간30XP·30코인 및 월간60XP·60코인도 변경하지 않았다. 의상120~300, 가구90~520, 기존 구매 친구300/450/600과 비교해 초반120~150, 후반300~375로 정했다.

표의3개=매일 활동3개(45기본XP/75코인); 6개=활동3+출석+일기+방명록(60기본XP/100코인+출석). 6개 예시는 출석이 매일20코인인 유효한 예시이며 기대값/보장값이 아니다. 실제 출석에 따라 해당 날짜 코인 추가는0~30이고 XP·아이템을 받을 수도 있다. `node scripts/simulate-friend-economy.mjs`로 실제 날짜 선정·처음 수행XP·원장을 적용해 계산했다. 신규XP0/90코인, 2026-10-08 시작, 소비 없음, 주월 보상 청구 없음, 미션 교체/반복 보상 없음이 가정이다. 주월 청구/출석XP/수행구성에 따라 달라진다. 표의 가격 일수는 해금 후 잔액0에서 활동3개 수입을 모으는 기준이며 해금 소요와 다르다. 같은 계산의 누적 코인(초기90포함)은 밀루 해금 때3개540/6개690, 도토 해금 때3개4065/6개4890이다. 해금 전 저축하면 바로 살 수 있다. 기존 공식을 유지하므로 LV25까지 수입이 많이 쌓이는 특성은 남으며 임의로 회수·보상 축소하지 않는다. 예방 효과가 검증된 수치가 아니다.
