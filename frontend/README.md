# MOCHI Frontend

최종 수정: 2026-10-08. React/Vite 웹과 Expo/React Native 모바일이 공유 게임 계산을 사용한다. 최신 상세 기능·저장 구조·백엔드 합의 표는 [FEATURE_SPEC.md](FEATURE_SPEC.md). 본문은 현재 상태, 과거 동작은 아래 변경 이력이다.

## 실행·검증

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5180 --strictPort
npm.cmd run build
node --test src/utils/*.test.js ../mobile/src/storage.test.mjs
node scripts/check-ui-review.mjs
```

웹 http://127.0.0.1:5180/, 앱은 [mobile/README.md](../mobile/README.md)의 Expo 8081. 터널 공개 설정을 바꾸지 않는다. 마지막 UI 검증은 임시 Edge 프로필의 자동 테스트로 실제 사용자 기록에 접근하지 않는다. 실제 iPhone/Android 키보드·터치·접근성은 별도 확인 필요하다.

## 현재 화면과 UI

홈은 기존 방/가구/캐릭터 중심 구도, 상단 코인·출석, 이름 아래 실제 LV/XP, 창문 근처 서울 시각을 유지한다. 설정·노랑 방문·분홍 방명록·일기 보조 메뉴, 오늘의 도전/꾸미기 주요 버튼. 아래 둥근 요약은 진행 중→시작 전→완료 순서이며 해당 미션으로 이동한다. 목표 상품은 미리보기·이름·현재/필요 코인·현재/필요 LV와 충족 여부를 표시한다. 목표 미선택 시 상점 진입만 제공한다. 돌봄 수치·버튼·가상 걸음·산책 코인은 없다.

공통 ScreenHeader로 44px 뒤로가기·21~22px 제목과 상단 간격을 맞춘다. 도전은 작은 구름 포인트와 한 줄 오늘/주/월 탭, 기록·취향 별도 진입, 중복 하단 메뉴 제거. 웹 phone-content/앱 메인 ScrollView의 단일 스크롤. 주요 버튼 파랑, 선택 연보라, 보상 노랑, 카드 크림. 장착 중·비활성·선택·해제를 구분한다. 에이투지체 실제 400/500/600·OS 폴백, 웹 WOFF2/앱 TTF, [라이선스](FONT_LICENSE.md). 배경·그림·저장 규칙을 UI 변경 때문에 바꾸지 않는다.

## 일일 미션과 일기

매일 작은 루틴 3개(출석/일기/다른 이웃 방명록) + 새로운 발견 3개, 총 6개. 각 영역 N/3 표시. 전체 완료 강제·벌점 없음. 고정 미션은 실제 기능 저장 성공에 연결하며 방문/초안/실패/샘플 글은 완료가 아니다. 출석은 기존 지급만, 일기는 일기 보기/쓰기, 방명록은 이웃 둘러보기. 활동은 시작(무보상)→해냈어요→완료; 보류/교체는 보상 없음. 날짜별 활동 3개는 저장돼 새로고침으로 바뀌지 않는다. 이전 전역 3회 제한을 사용하지 않고 날짜/활동 슬롯별 지급 원장으로 중복을 막는다. 선정·교체·인증의 출시 정책은 서버 합의 전이다.

오늘의 준비/바깥 발견/작은 연결의 기존 작은 행동 조건·부담 응답·같은 목적 대안 활용. 준비나 혼자 외출을 교류로 계산하지 않는다. 음악/음식은 언제든 수정하는 취향 프로필, 보상 없음.

홈/도전/기록에서 같은 날짜의 공통 일기 편집기를 연다. 80자 전용 입력 제거, 최대 2000자·공백 금지·한 줄 가능. 질문+다른 질문과 감정 5종은 선택 사항. 질문 변경은 글 유지/자동 삽입 없음. 초안 journalDrafts와 저장 본문 journals 분리, 이동/복귀·새로고침 복원, 초안은 스탬프/완료/보상 없음. 저장 중/성공/실패/재시도 제공, 실패 시 글 유지. 당일 수정·삭제·삭제 후 재작성 가능, 지난 날짜 읽기만. 삭제 시 본문/감정/답변/초안 정리, 날짜·완료·지급 원장 보존. 수정/재작성으로 보상·날짜 집계 증가 없음. 날짜 목록·월별 달력 유지.

## 성장·출석·상점

LV=1+floor(XP/100), 실제 신규 XP0/90코인/감자, 명시적 demo만 540코인. 현재 로컬 시연 활동 15XP/25코인, 새로운 행동 5XP 추가; 일기 15/25. 방명록 미션 추가 보상은 합의 전 보류. 출석은 기존 주간 계획의 XP5/8/10·코인10/20/30·가끔 옷/소품, 기존 지급 경로 한 번만. 전부6개 보너스 추가 없음. 서버는 다른 수치를 사용하므로 출시 보상 정책은 명세서 합의 표에서 확인한다.

주간 외출/교류 각2회·일기 다른 날짜3일은 각30XP/30코인, 월간 외출8회·일기10일 각60/60. 서울 월요일/월초 경계, 중복 집계/지급 방지·과거 원장 유지. 실제 행동은 사용자 확인, 센서 검증 아님.

정식 친구6: 감자 기본, 토끼LV3무료, 구름LV5/300, 양LV8/450, 거북LV12/600, 펭귄 누적 현실 행동10회(입력 제외)무료. 옷4종120~300·소품/풍경16종90~520. 구매/장착/배치/해제 별개, 일반 잠금 상품 모습/이름/가격/LV 공개. 목표1개 지정/해제/변경은 자동 구매 없음. 출석 획득도 목표 완료에 반영한다. 기존 애칭은 해당 친구만 이관, 소개는 수정 가능한 짧은 초안이다. 정식 친구의 깜빡임·터치/키보드·새 완료/새 의상 축하·모션 줄이기 유지.
