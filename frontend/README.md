# MOCHI Frontend

최종 갱신: 2026-10-06. 현실의 작은 외출·교류 도전으로 XP·코인을 얻고 독립된 친구·옷·집을 꾸미는 React/Vite 프론트입니다. 게임은 localStorage이며 실제 서버·계정·센서와 연결되지 않았습니다. 상세한 최신 동작과 저장/제약은 [FEATURE_SPEC.md](./FEATURE_SPEC.md), 과거 변경은 문서 마지막 이력에서 확인합니다.

## 실행과 검증

PowerShell에서는 npm.ps1 대신 npm.cmd를 사용합니다.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5180 --strictPort
npm.cmd run build
node --test src/utils/game.test.js src/utils/attendance.test.js src/utils/visitors.test.js
```

주소 http://127.0.0.1:5180/. 서버 터미널이 열려 있어야 합니다. preview는 빌드 후 npm.cmd run preview -- --host 127.0.0.1 --port 5180 --strictPort. macOS/Linux는 npm 사용. 포트 공개 설정을 바꾸지 않았습니다.

React/React DOM ^19.1.0(설치 19.3.0), Vite ^7.0.0(설치 7.3.6), Pretendard 1.3.9 웹폰트, JSX SVG 에셋. 로직 테스트 32개와 빌드를 확인합니다. 실제 브라우저 표면이 없어 이번 UI·모션·새로고침·작은 화면 직접 검증은 미수행입니다.

## 모바일 앱과 웹

주 모바일 프론트는 [mobile/README.md](../mobile/README.md)의 Expo SDK 57 / React Native 0.86.3 앱입니다. 홈·도전·상점·출석·설정·샘플 이웃/방명록을 네이티브 컴포넌트로 연결했고, 계산/데이터는 이 웹의 utils를 공유합니다. 아래 웹 구현도 기존 저장 데이터를 보존하기 위해 유지합니다. WebView로 감싼 구현이 아닙니다.

모바일은 `cd mobile` → `npm.cmd start -- --lan --port 8081`로 실행합니다. 웹 localStorage와 모바일 AsyncStorage는 별개입니다. 웹 설정의 **현재 기록 백업** JSON을 모바일 설정의 **백업·가져오기**에서 확인 후 가져옵니다. 기존 앱 기록은 먼저 복사할 수 있습니다. 기존 재화·아이템·배치·애칭·기록을 이관하며 보상을 다시 지급하지 않습니다. 실제 서버/로그인·센서·사진·알림·스토어 제출은 아직 연결되지 않았습니다.

## 현재 웹 화면

오늘의 도전 화면 내부의 상단 장식 메뉴는 제거하고 왼쪽 `<` 버튼으로 홈에 돌아갑니다. 달/고정 숫자 200/집/플러스 3개는 퀘스트에서 표시하지 않으며 실제 LV·XP·보유 재화와 다른 화면의 메뉴는 유지합니다. 네이티브 퀘스트도 `<` 복귀 버튼을 사용합니다.

홈의 방문하기 집 아이콘은 노랑, 방명록 메모 아이콘은 분홍이며 두 라벨은 bold(700)입니다. 기존 버튼 동작과 배치는 유지합니다.

데스크톱에서는 아이폰 형태의 검정 프레임·다이내믹 아일랜드·서울 시각 상태 바·홈 표시줄로 목업을 표시합니다. 신호/배터리는 장식입니다. 실제 휴대폰 폭(480px 이하)에서는 장식 프레임을 숨기고 100dvh와 안전 영역에 맞춰 앱을 표시합니다. iOS 입력 자동 확대를 줄이도록 입력 글자는 16px입니다. iOS 홈 화면 실행 메타 설정을 추가했지만 네이티브 앱/오프라인 PWA는 아닙니다. 상점 카드는 기기 폭에 맞춰 1열이며 기존 기능/재화/저장은 유지합니다. 실제 아이폰·Safari·가상 키보드는 아직 직접 확인하지 못했습니다.

홈 상단은 코인/출석 한 줄이며 실제 LV/XP는 캐릭터 아래 이름 밑에 표시합니다. 설정은 모서리, 방문/방명록은 방 안 작은 메뉴, 친구별 애칭은 캐릭터 근처 이름표입니다. 창문 근처 서울 날짜·시간, 방 아래 오늘의 도전·꾸미기를 먼저 배치하고 선택한 도전/목표 요약은 그다음에 표시합니다. 방은 368:500의 홈 전용 비율로 빈 벽/바닥과 상단 여백을 줄이고 기존 가구/풍경/의상·캐릭터 크기와 반응은 유지합니다. 짧은 화면에서는 필요한 스크롤을 허용합니다. 파스텔 참고 이미지 src/refe/image.png의 분위기를 참고합니다. 돌봄 버튼/수치/가상 걸음/산책 코인은 없습니다.

## 도전·추천·기록

| 갈래 | 내용 |
| --- | --- |
| 오늘의 준비 | 물 한 모금, 하루 시작(커튼/물), 한 줄 기록, 제철 음식 알아보기 |
| 바깥 발견 | 문밖 한 걸음, 짧은 외출, 1/5/10분 중 내 걸음 목표, 구매 또는 무료 동네 구경, 다른 길/쉼터 |
| 작은 연결 | 눈인사, 인사, 안부, 감사, 관심사 질문, 함께할 활동 제안. 답장/성사 불필요, 지인 없는 대안 포함 |

규칙 기반 후보는 익숙한/한 걸음/다른 방식 역할과 짧은 추천 이유를 제공합니다. 역할은 카테고리와 고정 대응하지 않습니다. 최근 기록과 선택적 부담 응답을 참고하고 응답 없이 반복했다는 이유로 난이도를 올리지 않습니다. 후보는 서울 날짜별 저장되어 새로고침으로 바뀌지 않습니다.

최대 3개 직접 선택, 하나만 완료해도 보상. 행동은 시작(무보상) → 해냈어요 → 완료. 기본 카드는 카테고리·제목/상태·행동 설명·보상·주요 동작을 간결하게 표시합니다. 바꾸기는 앱 안 하단 창에서 더 가볍게/더 짧게/다른 활동으로 중 선택하고, 나중에 하기는 바로 보류합니다. 대안이 없으면 현재 도전 유지. 교체로 완료/보상을 지급하지 않으며 취소는 저장을 바꾸지 않습니다. 닫기/바깥 클릭/Escape, 배경 스크롤 잠금·포커스 관리/복귀를 제공합니다. 추천 이유는 정보 버튼, 일일 한도는 공통 보상 안내에서 확인합니다. 한도 이후에는 추가 보상 없음 표시. 완료 카드는 간결하게, 부담 응답은 선택적 창으로 제공합니다. 세 갈래 수행 강제·전체 미완료 배지는 없고 단일 스크롤 유지입니다.

음악/음식 입력은 보상 없는 수정 가능한 취향 프로필입니다. 기존 최신 답변을 이관합니다. 도전의 하루 기록은 공백 차단·80자 저장으로 완료하며 기록·취향 탭에서 다시 읽고 당일 글만 수정합니다. 별도 일기 화면에서는 최대 2,000자 작성·수정과 날짜별 목록·월별 스탬프 달력을 제공합니다. 수정으로 보상이나 날짜 수가 증가하지 않습니다. 화면의 반복적인 수정·보상 안내는 생략하고 하루 기록 저장 성공만 짧게 표시합니다. 준비/외출/교류 완료는 분리 저장하고 앱의 샘플 방명록은 실제 교류로 자동 계산하지 않습니다.

| 집계 목표 | 조건 | XP/코인 |
| --- | --- | --- |
| 주간 외출 / 교류 | 해당 갈래 완료 각 2회 | 각 30/30 |
| 주간 일기 | 다른 날짜 3일 | 30/30 |
| 월간 외출 | 8회 | 60/60 |
| 월간 일기 | 다른 날짜 10일 | 60/60 |

진행률은 기록에서 자동 집계하며 달성 후 기간당 보상 1회 수령. 일간 서울 자정, 주간 월요일, 월간 1일 경계와 과거 기록 보존. 실제 활동은 사용자 확인이지 센서 검증이 아닙니다.

## 성장·출석

레벨 공식은 1+floor(XP/100) 유지, 기존 레벨/해금 후퇴 없음. 실제 신규 시작 0XP·90코인, 명시적 시연 initialGame({demo:true})만 540코인. 일간 기본 15XP·25코인, 최초 현실 행동 ID에 5XP 추가, 일간 보상 최대 3회. 프로필 입력은 보상 없음. 기존 XP/코인/보상/자산은 회수하지 않습니다.

출석은 월요일 고정 주간 보상표, 매일 1회, 결석/연속 불이익 없음. 새 XP 후보 5/8/10, 코인 10/20/30, 의상/소품 각 10% 포함. 기존 저장 계획의 보상 유지, 중복 의상/소품은 30코인. 출석 아이템은 레벨과 무관하게 착용/배치 가능.

월요일 시작·출석 제외 예시는 매일 산책+일기 및 집계 보상 수령 7일 LV.3, 14일 LV.7, 28일 LV.13. 첫날 1개 행동 후 115코인으로 달빛 전등(90) 구매 가능. 예방 효과 기준이 아니라 콘텐츠 진행 속도 가정입니다.

## 상점·친구·반응

상점/도전의 새 UI는 Pretendard·시스템 폴백을 상속하고, 제목 21~22px·카드 16px·본문 14px·보조 12~13px으로 구분합니다. 친구 소개/다른 도전 목록은 작은 꺾쇠 펼침과 네이티브 키보드 조작·포커스를 사용합니다. 목표는 둥근 보조 버튼의 목표로 선택/목표로 선택됨으로 표시하며 다시 누르면 해제합니다. 주요 구매/장착 버튼과 보조 동작은 색으로 구분하고 터치 높이 44px 이상을 확보합니다. 소개에는 짧은 캐릭터 소개만 표시합니다. 상점 카드는 펼친 옆 카드까지 늘리지 않으며 430px 이하 화면은 1열입니다. 홈 배치와 보상/저장 규칙은 유지합니다.

일반 잠금 상품은 모습·이름·가격·필요 레벨을 미리 보여주고 구매만 제한합니다. 기존 구매/컬렉션/옷장/배치/해제 기능을 재사용합니다. 갖고 싶은 목표 상품 1개를 지정·변경·해제하며 홈에서 코인/레벨 부족 조건을 따로 표시합니다. 목표는 자동 구매/장착하지 않고 출석 획득도 완료 상태에 반영합니다.

| 친구 | 획득 |
| --- | --- |
| 감자 | 기본 무료 |
| 복숭아 토끼 | LV.3 무료 |
| 구름 | LV.5·300코인 |
| 달빛 양 | LV.8·450코인 |
| 새잎 거북 | LV.12·600코인 |

의상 4종(120~300코인), 집 소품 16종(90~520코인), 해금 LV.1~12. 가격/레벨은 기존값 유지하며 상세 표는 명세서와 utils/clothes.js/decor.js에 있습니다. 구름·토끼·양·거북·펭귄은 색상 변경이 아닌 서로 다른 기존 SVG 외형을 유지합니다.

친구 소개는 catalog.js의 수정 가능한 짧은 초안입니다. 고유 이름과 친구별 애칭을 구분합니다. 기존 애칭은 이관 당시 장착 친구 한 명에게만 옮기며 원본 키를 보존합니다. 모든 친구에 기본 눈 깜빡임·터치/Enter/Space 하트·실제 완료/새 옷 착용 후 축하를 연결합니다. 반응 중 추가 입력 무시, 홈 복귀 시 대기 이벤트 한 번 소비, 구매/재렌더/재진입만으로 재생하지 않음. 동작 줄이기·타이머 정리·기존 옷/clipPath 유지. 미완료/미접속 탓하는 연출 없음.

## 이웃·방명록·설정

샘플 이웃 12명 중 서울 날짜별 3명 추천. 최근 방문, 이웃 저장/재방문, 내가 남긴 글에서 방명록 다시 보기, 응원/감사 반응을 추가합니다. 시연 글과 내 브라우저 작성 글을 구분합니다. 실제 상대에게 전달하거나 답장이 온 것으로 표시하지 않습니다. 공개 인기 순위 없음. 기존 내 집 방명록/좋아요 유지.

이름 설정은 친구별 애칭 12자 저장. 소리/알림 스위치·음량은 기존 메모리 UI이며 실제 오디오/알림은 없습니다.

## 저장·이관·제약

mochi.game.v1의 기존 XP/코인/완료/답변/친구/출석/소품과 mochi.wardrobe.v1을 유지합니다. challengeVersion:2로 분류 기록·프로필·일기를 무보상 1회 이관합니다. 새 필드 challengeDays/activityRecords/rewardDays/preferences/journals/journalDates/feedback/challengeChoices/targetItem/nicknames를 같은 게임에 저장합니다. 이웃 연결은 기존 방문 저장 방식에 맞춰 mochi.visitConnections.v1, 기존 글/좋아요 키 유지.

날짜 없는 구형 주/월 완료는 현재 기간으로 한 번만 무보상 이관하고 원본 보존. 같은 브라우저/origin 복원, 데이터 삭제/저장 차단/origin 변경은 제약. 다중 탭 동시 요청·변조·서버 인증은 현재 방어하지 않습니다.

기존 하루 기록과 같은 game.journals를 공유하며 기존 글을 보존한다. 도전 입력은 기존 80자/완료 보상을 유지하고, 기록 편집과 새 일기 화면은 2,000자다. 과거 기록 편집도 모든 저장 경로에서 막는다. 일기 화면 작성·수정 자체는 XP/코인을 지급하지 않는다. journalDates는 기존 글에서 기본값을 유도하는 작성 날짜 원장이다. 삭제하면 글과 해당 날짜의 day-diary 답변을 제거하되 완료·보상·작성 날짜는 유지한다. 주간/월간 날짜 집계는 삭제로 감소하지 않으며 재작성·보상을 중복 획득하지 못한다. localStorage/AsyncStorage의 기존 mochi.game.v1에 함께 저장되고 백업도 포함한다.
