# MOCHI Frontend

모찌를 돌보고 퀘스트 보상으로 캐릭터와 의상을 모으는 **React + Vite 프론트엔드 목업**입니다. 현재 구현된 화면은 홈·퀘스트·방명록·설정·상점 5개입니다. 백엔드는 별도 개발 중이며 이 프론트에는 아직 API가 연결되지 않았습니다.

최종 갱신: 2026-10-02. 전체 기능의 상세 동작과 제약은 [프론트 기능 명세서](./FEATURE_SPEC.md)를 참고하세요. 프론트 기능을 변경할 때 이 README와 명세서도 현재 코드에 맞춰 갱신합니다.

## 설치와 실행

Node.js와 npm이 필요합니다. 이 작업에서는 Node.js 24.21.0을 사용했습니다. PowerShell 실행 정책으로 `npm.ps1`이 차단되는 환경에서는 아래처럼 `npm.cmd`를 사용합니다.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev -- --host 127.0.0.1 --port 5180 --strictPort
```

접속 주소: **http://127.0.0.1:5180/**. 실행한 터미널을 유지해야 서버가 계속 동작합니다. `--strictPort` 옵션은 포트가 사용 중이면 자동으로 다른 포트에 뜨는 대신 오류를 표시합니다.

macOS/Linux에서는 같은 명령의 `npm.cmd`를 `npm`으로 바꿉니다. `npm run dev`만 실행하면 Vite 기본 포트 5173을 사용하며, 사용 중이면 다른 포트를 선택할 수 있으므로 터미널의 실제 주소를 확인합니다. 5180은 명령으로 지정한 실행 포트이며 `vite.config.js`에 고정되어 있지는 않습니다.

### 빌드와 검증

```powershell
npm.cmd run build
node --test src/utils/game.test.js src/utils/attendance.test.js
npm.cmd run preview -- --host 127.0.0.1 --port 5180 --strictPort
```

빌드 결과는 `dist/`에 생성됩니다. preview는 빌드된 결과 확인용이며 개발 서버와 동시에 같은 포트를 사용할 수 없습니다. 저장소 루트에서 `git diff --check`로 변경 파일의 공백 오류도 확인할 수 있습니다.

검증 명령은 게임 규칙 4개와 출석 규칙 5개 테스트를 실행합니다. 기본 캐릭터 제공, 보상 중복 방지, 레벨·코인 구매 제한, 구매 후 장착 유지, 자유 재장착, 무료 보상, 서울 자정·월요일 경계, 출석 기록 복원과 결석 후 보상을 확인합니다. 브라우저 자동화 연결이 없어 실제 화면과 클릭 동작은 별도 확인이 필요합니다.

## 기술과 화면 구성

| 항목 | 현재 구성 |
| --- | --- |
| UI | React / React DOM: `package.json` 범위 `^19.1.0`, 현재 lockfile 설치 버전 19.3.0 |
| 개발·빌드 | Vite: 선언 범위 `^7.0.0`, 현재 설치 버전 7.3.6, React 플러그인 |
| 글꼴 | 전체 Pretendard 1.3.9 웹폰트. 별도 사용자 설치 불필요. CDN 실패 시 sans-serif |
| 캐릭터·배경 | React SVG 컴포넌트, 참고 이미지 파일을 UI에 그대로 사용하지 않음 |
| 화면 이동 | React 상태로 전환. URL 라우터 없음 |
| 저장 | 브라우저 localStorage와 컴포넌트 메모리 |
| 디자인 | 파스텔 색, 둥근 카드·버튼, 약 390px 폭의 모바일 목업. 전체 반응형은 미완성 |

공통 상단에는 5개 화면 선택 버튼과 **LV·XP 진행률**이 있습니다. **서울 시간 시계는 홈 게임 화면의 집 안**, 상태 표시 아래에 작은 한 줄로 배치합니다. `Asia/Seoul` 기준으로 **오전 9:07 · 10월 2일**처럼 오전/오후·시·분과 월·일만 표시합니다. 매초 시간을 확인하고 탭을 다시 활성화하면 갱신합니다. 기기 시각을 기반으로 하며 서버 시간 동기화는 없습니다.

### 매일 출석과 주간 도장표

팝업 제목은 **이번주의 출석표**, 안내 문구는 **이번 주 N일 함께했어요. 언제든 반가워요.** 한 문장만 표시합니다. 주간 날짜·도장과 출석하기/닫기 버튼을 제공하고, 수령한 보상은 `+20 코인`처럼 짧게 표시합니다. 반복적인 규칙·동기부여 설명은 팝업에서 제거했습니다.

서울 기준 날짜가 바뀌는 **0시**에 앱이 열려 있으면 출석 팝업이 자동으로 뜹니다. 앱을 닫아두었다면 그날 처음 열 때 표시하며, 비활성 탭에서 돌아와도 날짜를 확인합니다. 출석표 버튼으로 언제든 다시 열 수 있습니다. 팝업은 닫거나 나중에 출석할 수 있고, 이미 보상을 받은 날에는 중복 보상을 지급하지 않습니다.

- 하루 한 번 출석하면 **코인 또는 XP 중 하나**를 랜덤 지급합니다. 후보는 코인 10/20/30 또는 XP 20/35/50이며 6개 후보가 같은 확률입니다.
- 도장표는 월~일 7칸에 실제 출석 날짜만 체크하고 이번 주 출석 일수를 표시합니다.
- **월요일 0시부터 새 주의 표**를 표시합니다. 이전 주 출석 기록과 지급한 XP·코인·컬렉션은 유지합니다.
- 연속 출석 조건·결석 불이익·누적 출석 수에 따른 팝업 제한은 없습니다. 결석 후 돌아와도 같은 방식으로 보상을 받습니다.
- 출석 XP도 레벨업·LV.3 무료 보상에 반영하며 캐릭터를 자동 변경하지 않습니다.
- 출석 기록은 게임 localStorage에 함께 저장합니다. 현재 기기 시각/프론트 기준이므로 서버 검증·다중 탭 동시 수령 방지는 후속 작업입니다.

## 홈: 캐릭터 돌봄

첫 방문에는 LV.1의 **꼬질 감자 모찌**가 제공됩니다. 홈은 방 배경, 현재 캐릭터와 옷, `MY`와 사용자 지정 이름, 레벨·배부름·행복·기운 상태, 요청 말풍선, 걸음 수와 코인을 표시합니다.

| 행동 | 현재 동작 |
| --- | --- |
| 밥 주기 | 배부름 +15, 밥 요청 숨김 |
| 놀아주기 | 행복 +5, 기운 -10, 잠 해제 |
| 치우기 | 청소 요청과 `치워줘!` 배지 숨김 |
| 재우기 | 잠자는 표정, 기운 +20 |
| 산책 가기 | 걸음 수 +500, 코인 +5, 잠 해제 |

초기 수치는 배부름 80·행복 95·기운 70·걸음 수 7,850이며 돌봄 수치는 0~100으로 제한합니다. 행동 메시지는 약 2.2초 표시합니다. 산책은 목업 버튼 동작이며 실제 걸음 센서와 연결되지 않았습니다. 돌봄 행동은 XP를 지급하지 않으며 시간 경과에 따른 수치 감소도 없습니다.

홈 이름을 누르면 설정에서 이름을 변경할 수 있습니다. 오른쪽 위 톱니바퀴와 하단 설정 버튼은 설정으로, 하단 상점 및 `코인으로 옷 사기`는 상점으로 이동합니다. 색상 팔레트는 크림·복숭아·민트·라벤더·바나나·하늘·딸기·흰떡 8종이며 일반 구름 모찌에 적용됩니다. 기본 감자와 별도 색상이 정해진 캐릭터는 고유 색상을 유지합니다.

## 퀘스트와 성장

```text
퀘스트 수행
→ XP와 코인 획득
→ 레벨 상승
→ 새로운 캐릭터·의상 선택지 해금
→ 사용자가 보상 구매·장착 선택
→ 캐릭터를 꾸미며 성장
```

**레벨업은 캐릭터의 강제 진화나 교체가 아닙니다.** 구매와 무료 보상도 현재 장착 캐릭터를 바꾸지 않습니다.

- 시작: LV.1, 누적 XP 0, 코인 540(목업용 시작 자금).
- 레벨 계산: `1 + floor(누적 XP / 100)`. 코인은 구매 화폐이며 사용해도 XP·LV는 줄지 않습니다.
- 오늘·이번 주·이번 달 탭에 각 3개, 총 9개 퀘스트가 있습니다.
- 완료 버튼으로 활동을 수동 확인하고 XP·코인을 동시에 지급합니다. 같은 퀘스트의 보상은 중복 지급하지 않습니다.
- 보상과 레벨업 결과를 안내하고 LV.3 및 특별 퀘스트 무료 캐릭터를 컬렉션에 추가합니다.
- 성장 퀘스트 제목은 Pretendard 한 겹으로 표시하며 겹쳐 보이던 글자 외곽선·그림자는 제거했습니다.

| 기간 | 퀘스트 | XP | 코인 |
| --- | --- | ---: | ---: |
| 오늘 | 잠깐 밖에 나가보기 | 100 | 30 |
| 오늘 | 내 시간에 일어나기 | 100 | 30 |
| 오늘 | 오늘의 하루 기록하기 | 100 | 40 |
| 이번 주 | 이번 주 산책 두 번 | 150 | 50 |
| 이번 주 | 일정한 생활 리듬 만들기 | 150 | 50 |
| 이번 주 | 하루 기록 다섯 번 | 150 | 50 |
| 이번 달 | 새로운 장소 가보기 | 200 | 80 |
| 이번 달 | 꾸준한 생활 이어가기 | 200 | 80 |
| 이번 달 | 한 달 기록 열다섯 번 | 200 | 80 |

수치는 목업 기준입니다. 실제 활동 검증, 일기 입력, 일·주·월별 퀘스트 갱신은 아직 없습니다. 현재 퀘스트는 저장 데이터당 한 번 완료할 수 있습니다.

## 상점: 캐릭터와 컬렉션

캐릭터·의상 탭, 보유 코인, 홈 이동 버튼을 제공합니다. 캐릭터 탭에서는 현재 장착 캐릭터와 보유 컬렉션을 구분해 표시하고 전체 목록/내 컬렉션 필터를 제공합니다.

| 캐릭터 | 획득 조건 | 비용 |
| --- | --- | ---: |
| 꼬질 감자 모찌 | 처음부터 1개 제공 | 무료 |
| 복숭아 구름 모찌 | LV.3 달성 보상으로 지급 | 무료 |
| 구름 모찌 | LV.5에서 구매 해금 | 300 코인 |
| 라벤더 모찌 | LV.8에서 구매 해금 | 450 코인 |
| 민트 모찌 | LV.12에서 구매 해금 | 600 코인 |
| 하루 친구 모찌 | 오늘 퀘스트 3개 완료 보상 | 무료 |

잠긴 캐릭터는 그림을 렌더링하지 않고 **`?` / 이름 `???` / `LV.?`**로 표시합니다. 레벨 조건을 충족하면 구매 가능한 캐릭터 모습·이름·가격을 공개하고, 특별 퀘스트 캐릭터는 획득할 때 공개합니다. 코인 부족·중복 구매·미보유 캐릭터 장착을 제한합니다.

구매한 캐릭터는 컬렉션에 추가되며 사용자가 **장착하기**를 눌러 선택합니다. **장착 해제**하면 기본 감자 모찌로 돌아가고 구매 기록은 유지됩니다. 언제든 이전 캐릭터를 다시 선택할 수 있습니다. 기본 캐릭터는 항상 제공되어 캐릭터 없는 상태는 없습니다.

디자인 참고: `src/refe/pot1.webp`의 작고 꼬질한 감자 느낌과 `src/refe/cha1.png`의 크림색 몸·하늘색 귀와 폭신한 꼬리·꽃/리본·반짝이는 눈을 SVG로 표현했습니다. 새싹은 제거했고, 넓은 눈 간격과 연한 볼터치, 채우기 색 없는 작은 입을 사용합니다. 다른 구름 form은 색상 변형입니다. 잠자는 표정과 의상 렌더링도 지원합니다.

## 상점: 의상 구매와 착용

모든 옷/내 옷장 필터와 미리보기, 레벨 제한·코인 부족 안내를 제공합니다. 구매 시 옷장에 추가하고 **입기**로 장착합니다. 미리보기는 실제 착용과 별개이며 **기본 모습 입기**로 옷을 해제합니다. 캐릭터를 바꿔도 의상은 보유하며 홈에 현재 착용한 옷을 표시합니다.

| 의상 | 필요 LV | 코인 | 구름 모찌 장식 |
| --- | ---: | ---: | --- |
| 하늘빛 맨투맨 | 1 | 120 | 구름 |
| 딸기 우유 티셔츠 | 1 | 180 | 하트 |
| 새싹 산책복 | 3 | 220 | 잎 |
| 별빛 잠옷 | 5 | 300 | 별 |

감자 캐릭터의 옷은 공통 별 장식을 사용하는 단순 목업입니다. 작은 아바타에는 의상이 아닌 캐릭터 중심 표현을 사용합니다. 의상은 잠겨 있어도 미리보기 가능하며, 캐릭터의 비공개 규칙과 구분됩니다.

## 설정

- **이름 지정:** 기본 `MOCHI`, 최대 12자. 앞뒤 공백 제거, 빈 이름 오류 안내. 저장 버튼/Enter로 홈 이름에 반영하고 브라우저에 저장합니다. 긴 이름은 홈 글자 크기를 줄여 표시합니다.
- **소리:** 배경 음악·효과음 스위치(초기 켬), 음량 0~100%(초기 70%). 실제 오디오 연결은 없습니다.
- **알림:** 일상 알림 스위치(초기 끔). 실제 알림이나 권한 요청은 없습니다.
- **설정 저장:** 목업 저장 완료 안내. 이름은 영구 저장 대상이며 소리·알림 옵션은 현재 페이지에서만 유지됩니다.
- **뒤로 가기:** 홈 이동.

## 방명록

8개의 샘플 글을 페이지당 4개 표시합니다. 작성자·날짜·내용·좋아요 수·아바타를 보여주며 60자 이내 글을 등록 버튼/Enter로 추가합니다. 공백 글은 등록하지 않고 새 글은 맨 위에 추가한 뒤 첫 페이지로 이동합니다. 작성자는 목업 이름 `나`, 날짜는 기기 로컬 날짜입니다.

좋아요는 선택·해제 시 개수를 변경하며 페이지 처음/끝에서는 이전·다음 버튼을 비활성화합니다. 답글 버튼은 표시만 있습니다. 서버 저장이 없어 방명록 화면을 떠나면 작성 글과 좋아요는 초기화됩니다.

| XP·코인·완료 퀘스트·보유/장착 캐릭터·날짜별 출석/보상 | localStorage `mochi.game.v1` | 동일 |
| 보유/착용 의상 | localStorage `mochi.wardrobe.v1` | 동일 |
| 돌봄·걸음 수·선택 색상·소리/알림 설정 | React 메모리 | 새로고침하면 초기화 |
| 방명록 작성·좋아요·페이지 | 방명록 컴포넌트 메모리 | 화면을 떠나면 초기화 |

컬렉션은 로컬 저장되며 계정 기반의 서버 영구 보관은 아직 없습니다. 포트·도메인이 바뀌면 별도 저장소가 됩니다. 브라우저 데이터 삭제·저장 차단 시 기록이 유지되지 않습니다. JSON 파싱 실패 시 초기값을 사용합니다. 현재 XP·코인·보유 기록은 서버에서 검증되지 않습니다.

## API 연결 및 향후 계획

백엔드 정보는 [backend README](../backend/README.md)를 참고합니다. 현재 프론트에는 `fetch`/axios API 호출이 없으며, 백엔드의 퀘스트·기록 구현이 있어도 프론트 연결 완료를 의미하지 않습니다.

다음 항목은 계획 또는 후속 개발 대상입니다.

- 사용자 계정, 서버 저장·동기화, 영구 컬렉션, 보상·구매 서버 검증.
- 실제 활동·걸음 센서 검증, 일기 입력, 반복 퀘스트 갱신.
- 액세서리·소품 구매, 방 배치·테마, 새 캐릭터군과 콘텐츠 해금.
- 실제 소리·알림, 설정 저장 연결, 방명록 API와 답글.
- 기록 화면(수면·활동·기분·하루 리듬), 지원 연결 카드, 기록/퀘스트 없음 등 상태별 화면.
- 데모 조작 패널(합성 인물·날짜 전환), 심사위원 보기(점수·단계·판단 근거).
- 완전한 모바일 반응형, 실제 브라우저 상호작용·통합 테스트.

## 작업 및 문서 갱신 규칙

- 작업 브랜치는 `영주`입니다.
- 사용자 허락 없이 커밋·푸시하지 않습니다. 허락받은 푸시는 `origin/영주`로 진행합니다.
- 기능 추가·변경·삭제 시 [FEATURE_SPEC.md](./FEATURE_SPEC.md)의 동작·수치·저장 방식·제약·이력을 함께 수정합니다.
- README의 실행 방법·기능 요약도 코드와 일치시키고, 미구현 계획을 완료 기능으로 표시하지 않습니다.
