# MY MOCHI UI 기준

최종 수정: 2026-10-10. 이 문서는 현재 UI를 설명한다. 캐릭터·의상·가구·방 일러스트와 소셜 로그인 제공사 색상은 이 팔레트의 적용 대상이 아니다.

## 색상과 관리 위치

웹·모바일의 원본 토큰은 `src/design/tokens.js`이다. 웹 CSS 변수는 `src/design/tokens.css`, 공통 버튼·선택·상태 규칙은 `src/design/ui.css`에서 관리한다. 화면 배치는 `styles.css`, 네이티브 공통 컴포넌트는 `mobile/src/ui.jsx`를 사용한다.

hover #6B59B3, pressed #5F4FA3는 보라에서 파생한다. 밝은 살구 표면은 #FCECE3, 비활성 배경은 #F5F6F1이다. 입력창·보조 버튼의 경계는 구분선보다 진한 #80958F를 사용하고 포커스는 대표색으로 표시한다. 오류 #A13C3C / #FFF0ED, 경고 #785522 / #FFF1D9는 의미 있는 상태에만 사용한다.

`node scripts/design-tokens.mjs --write`로 CSS 변수를 생성하고, `node scripts/design-tokens.mjs`로 동기화와 대비를 확인한다. 일반 텍스트 대비는 4.5:1 이상으로 검사한다. 대표색/밝은 글자는 4.75:1, 본문/표면 9.74:1, 보조 글자/표면 4.91:1이다. 연한 보라·살구 표면에는 본문색을 사용한다. #D8E2DC는 비대화형 구분선이며 포커스 표시를 대신하지 않는다.

## 공통 UI 규칙

- 주요 행동은 보라 채움/밝은 글자, 보조 행동은 밝은 표면/테두리, 부가 행동은 텍스트 버튼이다. 활성 탭은 보라 채움과 체크, 완료·장착은 상태 문구/체크와 연한 표면으로 구분한다. 비활성 버튼은 밝은 회색 표면과 보조 글자를 사용한다.
- 기본 버튼 곡률 14px, 카드 18px, 주요 터치 영역 44px 이상. 일반 버튼은 알약 모양으로 만들지 않는다. 큰 입체 그림자와 일반 UI의 그라데이션을 사용하지 않는다.
- A2z 실제 400/500/600과 기존 폴백을 유지한다. 제목 21~22px/600, 카드 제목 16~18px/600, 본문 14~15px/400, 버튼 14~15px/500, 보조 정보 12~13px/400~500. 입력은 모바일에서 16px을 유지한다.
- 공통 아이콘은 24 좌표계, 1.7px 선과 둥근 끝을 사용한다. 경로는 `src/design/icons.js`, 웹 `UiIcon.jsx`와 네이티브 `UiIcon.jsx`가 공유한다. 감정 선택 이모지와 실제 상품 그림은 별개다.

## 화면 표현

홈은 방과 캐릭터를 유지하고 주요 행동만 보라으로 강조한다. 미션은 ‘매일 하는 3가지’의 체크리스트 아이콘/간결한 행과 ‘오늘의 새로운 3가지’의 나침반 아이콘/설명 카드로 구분한다. 일기는 밝은 종이 표면과 작은 날짜 도장, 방명록은 봉투와 통일된 편지 표면, 보상 안내는 작은 살구 스티커를 사용한다. 상점 카드 배경은 통일하고 상품의 고유 색을 살린다. 로그인 워드마크는 보라이며 공식 카카오·Google 버튼 이미지는 그대로 사용한다.

## 보존 범위

이번 UI 변경은 미션 선정·완료·보상·가격·해금·구매·저장 구조를 변경하지 않는다. 캐릭터 도형·의상·모션과 방 배경을 유지한다. 별도 요청된 설정 로그아웃과 두 안내 문구 제거는 함께 반영했다. 실제 인증 어댑터는 미연결이며, 개발 미리보기 로그아웃은 로그인 화면 복귀와 preview 쿼리 제거만 수행하고 게임 기록을 삭제하지 않는다.

## 검증

웹 360/390/430px에서 홈·미션·일기·상점·이웃·방명록·로그인을 렌더링하고 가로 넘침·실제 적용 글꼴·검사 대상 텍스트 대비를 확인한다. 짧은 390×568 화면에서도 스크롤로 접근한다. 변경 전후 캡처는 `artifacts/ui-review/palette-before-*`, `palette-after-*`에 있다. 대비 자동 검사는 CSS 배경 기준이며 장식 이미지·공식 로고 픽셀의 대비를 평가하지 않는다. 실제 iPhone/Android와 소셜 인증은 별도 검증이 필요하다.

Expo Router는 screen을 예약 매개변수로 처리하므로 동적 경로 파일을 [screen].jsx에서 [page].jsx로 변경했다. /quest·/shop 등 실제 주소와 기존 이동 목적, 인증 조건은 유지한다. 라우터 내부에서 screen 매개변수가 제거되어 /undefined로 이동하던 충돌을 예방한다.

실행 결과: 웹 360/390/430px 및 짧은 화면 검사를 통과했다. Expo 개발 웹에서는 390px 주요 7개 화면과 메뉴 이동·로그아웃을 확인했다. 웹 빌드, 모바일 lint/typecheck 및 iOS/Android/web export, 기존 67개 테스트가 통과했다. 실제 네이티브 기기 실행은 미확인이다. Expo 웹의 공유 SVG에서 accessible 속성에 관한 비차단 콘솔 경고가 남아 있으며 캐릭터 외형은 수정하지 않았다.

## 출석 버튼 (2026-10-11)
출석표 진입 버튼은 웹 attendance-entry / 모바일 AttendanceButton을 공통 사용한다. 밝은 표면, 진한 글자, 입력 경계색 테두리, A2z500 14px/22px, 최소44px 터치 영역, 14px 곡률을 화면과 관계없이 유지한다. 홈의 전용 CSS는 위치만 담당한다. 출석 지급은 주요 행동, 닫기는 보조 행동이며 지급 완료의 비활성 상태는 기존 규칙을 따른다.
