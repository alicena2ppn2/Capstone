# 퀘스트 개편: 백엔드 팀 협의

최종 수정: 2026-10-14. 이번 구현은 웹/모바일의 로컬 콘텐츠·추천·안내·저장이다. backend 코드는 수정하지 않았다. 교수님 피드백은 기존 일상 활동을 이어가기와 구체적인 방법 안내의 필요성, 방명록 도움이 검증되어야 한다는 점이다. 익숙한2+선택적 확장1 및 구체적인 배정 규칙은 팀 설계이며 임상적 치료/고립 예방 효과를 검증한 기준이 아니다.

## 데이터 보존 및 재개

기존 mochi.game.v1/모바일 game 저장을 사용한다. preferences.missions와 missionModes는 없는 경우 기본값으로 읽고 현재 XP/코인/보유/과거기록/일기를 초기화하지 않는다. 신규 생활활동 ID에만 기존 최초 수행 보너스가 적용되고 기존 문구 수정 ID는 유지한다. 오늘 배정은 선호 변경·방명록·완료로 자동 교체하지 않는다. 실제 서버 API/토큰/계정별 동기화 연결은 별도 작업이며 이번에 추정 경로나 토큰을 추가하지 않았다.

서버 근거: backend/app/missions.py(상수·pick_missions·is_complete·settle_coins·level_from_xp), backend/app/main.py(finish_and_pay·auto_complete·미션 제출·일기 저장/삭제·방문·방명록), backend/app/db.py(coin_ledger 지급 원장).

교체 로컬 규칙 보완: 같은 카테고리 제한 없이 시간/제외/부담 상한을 지키고 넘긴 그룹은 서울 날짜별로 보존한다. 다시 보기는 명시적 동의가 있어야 하며 오늘 완료/다른 슬롯 중복 제한을 해제하지 않는다. 이를 서버 배정/슬롯 지급 원장과 맞추는 계약은 미합의이고 이번에 서버/API를 변경하지 않았다.

현재 UI 보완: 방법 보기·수행 수준 선택은 제거했고 카드 한 문장으로 안내한다. 이전 수준/진행 조건은 읽기 전용으로 보존하며 새 시작 시 criterion을 고정한다. 서버 계약은 이번에 변경하지 않았다.
