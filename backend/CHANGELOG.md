## 2026-10-19 — 레벨 곡선 완화 · 인사·안부·운동은 '했어요' · 방명록은 매일 미션에서 뺌

**브랜치** `quest-pacing` (#62 위에)

팀 분석 4·5절을 코드로 확인한 뒤 고침.
- **레벨**: 다음 레벨까지 100 + 150×(n−1) → **100 + 35×(n−1)**. LV.25(도토) 43,800 → 12,060 XP, 하루 200~400 XP면 1~2달 (예전 3~10달). 이미 쌓인 XP는 그대로라 기존 사용자는 레벨이 올라감 (데모 LV.12 → LV.22)
- **완료 확인**: 새 종류 `done`("했어요" 체크, 보상은 원래대로). 인사·안부 11개(c1~c3)와 운동 5개를 사진 → done. 10/15 "걸음 말고는 모두 사진" 결정을 바꿈 — 인사까지 사진을 요구하면 행동보다 인증이 일이 돼서. 사진은 하늘·산책·정리처럼 사진이 결과인 미션에만
- **데일리 미션**: 방명록 남기기를 뺌 (팀 결정 10/19, 방문하기만 남김). 의무로 두면 완료용 짧은 글이 늘어서. 방명록 쓰기·친밀도는 그대로. 매일 미션 8 → 7개
- 앱·웹: '했어요' 버튼, 웹 홈 요약은 서버 미션 그대로(기기 목록과 섞여 방명록이 보이던 것), 미리보기 데일리도 방명록 → 이웃 방 놀러 가기, "매일 하는 3가지" → "데일리 미션"
- 이미 배정된 오늘 미션(예전 종류)은 그대로, 내일 배정부터 새 규칙
- 테스트 267개 통과 (바뀐 규칙에 맞춰 레벨 값·데일리 목록·종류 검사 고침)
