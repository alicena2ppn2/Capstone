# Backend

데이터 생성 → 지표 계산 → 판단(규칙 엔진) → 에이전트·퀘스트 → API 제공을 담당합니다.
범위: **홈(침실) · 퀘스트 · 기록 · 지원 연결 카드** 4개 화면 + 데모 흐름.
스택: **Python, FastAPI**
마감: **10/22 발표** — 실제 스마트폰으로 걷기 → 데이터 전달 → 미션 판정 → AI 응답 → 캐릭터 말풍선까지 하나의 흐름으로 시연

| 영역 | 내용 |

| 지표 계산 | 걸음수 중앙값, IS, 수면 중간점, 결측 |
| 규칙 엔진 v0.2 | 점수 → 게이트 → 2주 지속 → 안전장치 → 단계 + 유형 태그 |

## API 목록 (안)

| API | 용도 |
|---|---|
| `GET /users/{id}/home` | 캐릭터 상태, 말풍선 문장 |
| `GET /users/{id}/quests/today` | 오늘의 퀘스트 |
| `POST /quests/{id}/complete` | 퀘스트 완료 (기록하기 등 자기 입력용) |
| `GET /users/{id}/records?range=day\|week\|month` | 기록 탭 문장 + 하루 리듬 띠 데이터 |
| `POST /users/{id}/checkin` | 오늘 기분 입력 |
| `POST /users/{id}/chat` | 에이전트 대화 |
| `GET /users/{id}/support` | 지원 연결 카드 내용 (해당 단계일 때만) |
| `GET /admin/users/{id}/explain` | 심사위원용: 점수·단계·근거 |
| `POST /demo/advance` | 데모: 날짜 넘기기 |

> **원칙:** 사용자용 API는 원점수를 내려주지 않는다. 점수는 `/admin` 쪽에서만 제공.
