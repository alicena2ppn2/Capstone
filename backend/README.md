# Backend

미션으로 행동을 유도하는 서버입니다. 밖에 잘 나가지 않는 사용자에게 하루 미션(하늘 사진 올리기, 동네 맛집 찾아보기, 주제 일기 쓰기 등)을 주고, 해내면 코인과 경험치를 줍니다. 경험치가 쌓이면 레벨이 오릅니다.

- 스택: Python, FastAPI, SQLite
- 프론트: React (`frontend/`, 기능 명세는 `frontend/FEATURE_SPEC.md`)
- 마감: 10/22 발표 — 휴대폰으로 걷기 → 걸음 전달 → 미션 판정 → 캐릭터 반응까지 한 흐름으로 시연

## 실행

```bash
cd backend
python -m venv .venv
.venv/Scripts/activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload   # API 문서: http://localhost:8000/docs
pytest                          # 테스트
```

환경변수 (모두 선택)

| 이름 | 기본값 | 용도 |
|---|---|---|
| `CAPSTONE_DB` | `backend/app.db` | SQLite 파일 경로 |
| `CAPSTONE_UPLOADS` | `backend/uploads/` | 사진 저장 폴더 |
| `CORS_ORIGINS` | `http://localhost:5173` | 프론트 주소 (쉼표로 여러 개) |

## API

| API | 하는 일 |
|---|---|
| `POST /users/{id}/steps` | 하루 걸음 수 올리기 (앱 만보기 → 서버) |
| `GET /users/{id}/home` | 걸음, 걸음 목표(8,000보), 코인, 레벨, 출석 여부, 미션 진행, 말풍선 |
| `GET /users/{id}/missions/today` | 매일 고정(출석·걸음·지난주보다·일기·방문·방명록) + 매일 바뀌는 3개 (그날 처음 부를 때 정해지고 하루 동안 고정) |
| `POST /users/{id}/missions/{mission_id}/complete` | 완료 판정 → 코인·경험치 지급 (중복 지급 없음), 레벨업 여부 |
| `POST /users/{id}/attendance` | 출석하기 (앱을 열 때 호출, 하루 한 번 보상) |
| `POST /users/{id}/photos` | 사진 업로드 → `photo_id` (jpeg·png·webp·heic, 10MB 이하) |
| `GET /photos/{photo_id}` | 사진 보기 |
| `GET /users/{id}/diary/topic` | 오늘의 일기 주제 |
| `PUT /users/{id}/diary/{date}` | 일기 쓰기·고치기 (글·기분·사진, 오늘의 주제 사용 여부). 일기 미션이 있으면 자동 완료 |
| `GET /users/{id}/diary/{date}` | 하루 일기 보기 |
| `GET /users/{id}/diary?from=&to=` | 일기 목록 (기록 탭) |
| `GET /users/{id}/coins` | 코인 잔액 |
| `GET /users/{id}/level` | 레벨·경험치 |
| `POST /users/{id}/visits` | 친구 방 놀러 가기 (`{id}` = 방 주인, body에 `visitor_id`). 방문한 사람의 방문 미션 자동 완료 |
| `GET /users/{id}/visits` | 오늘 내 방에 놀러 온 친구 |
| `GET /users/{id}/rooms/recommended` | 놀러 갈 만한 친구 방 (최근 7일 안에 앱을 쓴 사람) |
| `GET /users/{id}/guestbook` | 방명록 목록 (`{id}` = 방 주인) |
| `POST /users/{id}/guestbook` | 방명록 남기기. `author_id`(쓴 사람)를 넣으면 쓴 사람의 방명록 미션 자동 완료 |

날짜를 받는 API는 `?date=YYYY-MM-DD`로 날짜를 바꿀 수 있습니다 (발표 데모에서 날짜 넘기기).

## 미션 규칙

**매일 고정 6개** (`category: daily`)
- 출석하기: 앱을 열 때 `POST /attendance`
- 오늘 걸음 채우기: 8,000보 이상 (서버에 올라온 오늘 걸음으로 판정)
- 지난주보다 많이 걷기: 최근 7일 하루 평균을 넘는 다음 100보 단위. 최근 7일 중 걸음 기록이 4일 이상일 때만 나옴
- 오늘의 일기 쓰기: 설명에 오늘의 추천 주제가 들어감. 주제와 상관없는 일기도 인정. 기록 탭에서 쓰면 자동 완료
- 친구 방 놀러 가기: 다른 사람 방을 방문하면 자동 완료
- 방명록 남기기: **다른 사람 방**에 쓰면 자동 완료 (내 방에 쓴 건 제외)

**매일 바뀌는 3개**
- 어제 걸음이 1,000보 미만이거나 평소(최근 28일 중앙값)의 절반 미만이면 "안 나간 날"
  - 안 나간 날: 밖으로 한 발 + 집에서 + 찾아보기
  - 나간 날: 기록 + 집에서 + 찾아보기
- 같은 사람·같은 날은 항상 같은 미션, 최근 이틀 동안 준 미션은 가능하면 피함

**분류** (`missions.json`의 `category`)

| 분류 | 예시 |
|---|---|
| `outdoor` 밖으로 한 발 | 하늘 사진 올리기, 가까운 공원 가서 사진, 음료수 사 오기, 어제보다 많이 걷기 |
| `home` 집에서 | 밥 사진, 창문 열고 환기한 사진, 이불 개기 |
| `explore` 찾아보기 | 동네 맛집 찾아 적기, 상영 중인 영화, 좋아하는 음악 |
| `record` 기록 | 감사한 일 세 가지, 오늘 기분 한 단어 |

**완료 판정** (`kind`)

| kind | 완료 조건 |
|---|---|
| `photo` | 본인이 업로드한 사진 `min_count`장 이상 |
| `list` | 서로 다른 항목 `min_count`개 이상 (`prompt`가 있으면 그 답도 필요, 예: 사는 동네) |
| `text` | 빈칸이 아닌 글 |
| `diary` | 그날 일기 저장 (주제는 추천일 뿐) |
| `guestbook` | 그날 다른 사람 방에 방명록을 남긴 기록이 있음 (서버가 확인) |
| `visit` | 그날 다른 사람 방을 방문한 기록이 있음 (서버가 확인) |
| `checkin` | 출석 API 호출 |
| `steps` | 서버에 올라온 오늘 걸음이 목표 이상 |

**걸음 목표**
- 기본 8,000보 (매일 고정 미션)
- "지난주(최근 7일 평균)보다 많이 걷기"는 매일 고정, "어제보다 많이 걷기"는 매일 바뀌는 미션. 둘 다 기록이 있을 때만 나오고 목표를 기록으로 정함 (기준을 넘는 다음 100보 단위)

**보상** — 프론트 `frontend/src/utils/game.js`의 '오늘' 퀘스트 수치에 맞춤

| 미션 | 코인 | 경험치 |
|---|---:|---:|
| 사진·찾아보기·걸음·기록·방문·방명록 미션 | 30 | 100 |
| 오늘의 일기 쓰기 | 40 | 100 |
| 출석하기 | 10 | 10 |

- 매일 바뀌는 3개를 모두 끝내면 응답에 `all_done: true`. 프론트는 이때 특별 캐릭터(하루 친구 모찌)를 줌 → 상점 서버 저장 때 백엔드에서 지급
- 레벨: 프론트와 같은 공식 `LV = 1 + 누적 XP // 100`. 코인은 쓰면 줄지만 경험치는 줄지 않음

**일기 주제**: 사용자마다 순서를 섞어 하루 하나. 50일 동안 같은 주제가 다시 나오지 않음
