# 게임 규칙 기준표 (2026-10-19)

**원칙: 로그인한 계정의 코인·XP·레벨·구매·지급은 서버가 최종 기준이다.**
앱·웹은 서버 결과를 보여 주고, 서버 없이 쓰는 개발용 미리보기만 기기 안 규칙(`shared/`)으로 돌아간다.

## 항목별 기준

| 항목 | 서버 기준 (최종) | 앱·웹 화면 | 서버 없는 미리보기 |
|---|---|---|---|
| 미션 배정 | 서버가 하루 미션을 배정 (`app/missions.py`) | 서버 미션만 보여 줌 | 기기 안 고정 3 + 변동 3 |
| 미션 새로고침 | 하루 3번 (`REROLLS_PER_DAY`) | 서버 응답의 남은 횟수 | 넘긴 활동 기억 |
| 보상 | 밖 20코인 · 집 12 · 일기 15 · 스스로 5, XP 50 (스스로 25), 단계 +5, 주간 50코인·100 XP — [ECONOMY.md](../backend/ECONOMY.md) | 서버가 준 값 | 같은 표를 따름 |
| 레벨 | 다음 레벨까지 100 + 150×(레벨−1) XP (LV.2 100, LV.3 350, LV.12 9,350) | 서버 레벨을 그대로 표시. 상점 해금도 서버 레벨로 판정 | 앱 공식 (`levelProgression.js`, 하루 약 60 XP 기준) |
| 상점 · 장착 · 방 꾸미기 | 서버가 코인 차감·소유·배치를 기록 | 서버 결과 표시, 거절되면 그 이유 표시 | 기기 안 기록 |
| 출석 | 연속 출석 1~7일차, 하루 빠지면 1일차 | 서버 출석표 | 같은 규칙 |
| 일기 | 하루 하나, **지운 날은 다시 쓸 수 없음**, 받은 보상은 그대로 | 기기에 저장 → 서버 저장 결과를 알림 (저장됨 / 서버 저장 실패 · 다시 저장). 지우기는 서버 먼저 | 같은 규칙 (지운 날 다시 못 씀) |

## 저장과 연결

| 상황 | 동작 |
|---|---|
| 서버에 연결이 안 됨 (처음) | 기기 기록으로 조용히 바꾸지 않고 "서버에 연결하지 못했어요 · 다시 시도" |
| 쓰는 도중 연결이 끊김 | 마지막으로 받은 서버 기록을 보여 주고 위에 "다시 연결" 안내 |
| 일기 서버 저장 실패 | 기기에는 남아 있고, "다시 저장" 버튼으로 재시도 |
| 기기 안 기록 | 로그인 계정마다 따로 (`mochi.u.<계정id>.…`). 예전 기록은 처음 로그인한 계정 하나에게만 옮김 — [`shared/storage/accountKeys.js`](../shared/storage/accountKeys.js) |
| 계정 삭제 | 서버 기록 삭제 + 이 기기의 그 계정 칸과 예전 기록 삭제 (다른 계정 칸은 그대로) |

## 바꿀 때

규칙을 바꾸면 이 표와 서버(`backend/app/missions.py`·`main.py`), `shared/features/`를 함께 고치고 테스트로 맞춘다.
