# 코인·경험치 밸런스 (2026-10-16)

상점 가격(친구 300~650, 옷 120~400, 집 꾸미기 80~520)은 그대로 두고, **미션 하나가 주는 보상을 줄여서** "갖고 싶은 것을 사는 데 며칠 걸리나"를 맞췄다.

## 왜 바꿨나

예전 값(밖 50·집 30·일기 40코인, 미션마다 100 XP)으로 하루 미션을 다 하면:

| | 코인 | XP |
|---|---|---|
| 데일리 미션 5개 | 200 | 500 |
| 오늘의 활동 3개 | 약 126 | 300 |
| 출석·주간 미션 등 | 약 30 | — |
| **합계** | **약 355 / 하루** | **약 800 / 하루** |

→ 집 꾸미기(100)는 몇 시간, 친구(300~650)는 1~2일, 상점 전체(약 12,800)를 **6주**면 다 산다. 레벨도 설계(`missions.py`의 "하루 400 XP면 LV.12까지 약 24일")의 두 배로 올랐다. 살 것이 금방 없어지면 모으는 재미(목표)가 사라진다.

## 참고한 것

- **Habitica** (오픈소스 습관 RPG, [HabitRPG/habitica `scoreTask.js`](https://github.com/HabitRPG/habitica/blob/develop/website/common/script/ops/scoreTask.js)): 할 일 하나의 골드는 `delta × 난이도 × (1 + 0.02 × 지각)` 정도로 **작고**, 연속(streak)마다 1%씩만 더 준다. 상점 물건 하나를 사려면 며칠~몇 주 꾸준히 해야 한다 → 미션 보상은 작게, 꾸준히 하면 쌓이게
- **수도꼭지(faucet)·배수구(sink)** 설계: 하루에 들어오는 재화가 쓰는 곳보다 조금만(약 1.1~1.3배) 많게, 그리고 "첫 큰 구매까지 걸리는 시간"으로 맞춘다 ([Why Economies Break Games](https://www.strayspark.studio/blog/game-economy-balancing-spreadsheets), [MMORPG Faucets](https://www.gamebanshee.com/9x94))
- **Finch** (자기 돌봄 앱): 목표를 이룰수록 무지개 돌을 더 받고, 그 돌로 옷·집 꾸미기를 산다 — 우리와 같은 구조 ([Finch 소개](https://www.internetmatters.org/advice/apps-and-platforms/wellbeing/finch/))

## 바꾼 값 (`app/missions.py`)

| 보상 | 전 | 후 |
|---|---|---|
| 밖에 나가는 미션 (걸음·밖 사진) | 50코인 · 100 XP | **20코인 · 50 XP** |
| 집에서 하는 미션 (방문·방명록 포함) | 30코인 · 100 XP | **12코인 · 50 XP** |
| 일기 | 40코인 · 100 XP | **15코인 · 50 XP** |
| 스스로 체크 | 10코인 · 50 XP | **5코인 · 25 XP** |
| 단계가 오를 때마다 | +10코인 | **+5코인** |
| 주간 미션 (자연 속 산책 2번) | 100코인 · 200 XP | **50코인 · 100 XP** |
| 출석표 (1~7일차) | 그대로 (10·20·30코인, 5·8·10 XP, 7일차 옷·소품) | |
| 친밀도 레벨업 | 그대로 | |

밖 미션이 집 미션보다 많이 주는 순서(외출을 이끄는 장치)는 그대로다.

## 바꾼 뒤: 사는 데 며칠?

하루에 다 하면 약 **146코인 · 400 XP**, 보통(70% 정도) 하면 약 **100코인**.

| 사고 싶은 것 | 다 하는 날 | 보통 하는 날 |
|---|---|---|
| 집 꾸미기 80~100 | 반나절~1일 | 1일 |
| 옷 120~400 (평균 260) | 약 2일 | 약 2~3일 |
| 친구 300 | 약 2일 | 약 3일 |
| 친구 650 | 약 4~5일 | 약 6일 |
| 상점 전부 (약 12,800) | 약 3달 | 약 4달 |

레벨은 설계대로 하루 약 400 XP → LV.12까지 약 3~4주.

## 앞으로 볼 것

- 실제 사용자 기록이 생기면 "첫 친구를 사기까지 걸린 날"의 중앙값으로 다시 맞춘다 (목표 3~5일)
- 코인이 너무 쌓이는 사람이 생기면 새 상품(계절 옷·한정 꾸미기)으로 쓸 곳을 늘린다 (배수구)
- 휴대폰 기록만 쓰는 모드(서버 없음, `shared/features`)는 아직 예전 값
